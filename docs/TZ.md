# Техническое задание (ТЗ) — CV Builder

## 📖 Описание проекта
Необходимо реализовать веб-приложение **CV Builder** (конструктор резюме), требования и дизайн которого представлены в Notion (см. раздел [🔗 Ресурсы](#-ресурсы)).

  > *Примечание:* При отсутствии напарника задача выполняется индивидуально в полном объёме до дедлайна.
- **Вводный этап:** После изучения требований обязателен созвон с ментором для согласования стека технологий (UI-библиотека, State Management и сопутствующие инструменты).
- **Дедлайн:** 4 недели с момента старта.

### Data fetching: без Apollo Client

**Apollo Client не используется.** Проект на Next.js (App Router), поэтому загрузка, кэширование и обновление данных выполняются средствами фреймворка:

- **Чтение данных** — запросы к GraphQL-бэкенду из **Server Components** (обычный `fetch` с `POST` и телом GraphQL-запроса), без клиентского рантайма и без дублирования кэша.
- **Кэширование и инвалидация** — кэш `fetch` Next.js: `next: { revalidate, tags }`, `revalidateTag` / `revalidatePath`.
- **Мутации** — **Server Actions** с последующей инвалидацией затронутых тегов/путей.
- **Клиентское состояние** — только UI-состояние (черновик формы в редакторе) через согласованный state manager; серверные данные в глобальный клиентский store не дублируются.

**Почему:** Apollo — тяжёлый клиентский слой с собственным кэшем, который дублирует кэширование Next.js и усложняет SSR. Нативный подход даёт меньше зависимостей, меньше клиентского JS и корректную работу SSR/SSG «из коробки».

> ⚠️ Отступление от исходной формулировки требований (там указан Apollo Client) — **согласовать с ментором** до начала активной разработки.

### Архитектура фронтенда: Feature-Sliced Design (FSD)

Код организуется по принципам **Feature-Sliced Design**: `app` → `features/<domain>` → `shared` → `lib`, слой импортирует только нижележащие. Полное дерево — `docs/STRUCTURE.md`.

| Слой | Расположение | Назначение |
|---|---|---|
| App | `src/app` | Маршруты и layout'ы Next.js (App Router), route groups `(auth)` / `(dashboard)`, тонкие файлы без бизнес-логики |
| Features | `src/features/<domain>/{ui,api,model}` | Страницы и пользовательские сценарии: UI, запросы / Server Actions, типы и схемы |
| Shared | `src/shared` | Переиспользуемая инфраструктура: UI-kit, API-клиент и сессия, config, helpers, hooks, types |
| Lib | `src/lib` | Утилиты библиотек (`cn()` и т.п.) |

Страницы не выносятся в отдельный слой `views`: они живут в `features/<domain>/ui`, а `src/app` содержит только тонкие маршруты. Работа ведётся **командой из двух человек** (парная разработка, см. раздел «Формат работы»).

## 🚫 Страницы ошибок

Этап «страницы ошибок»: три экрана — 404, отсутствие сети, неподдерживаемое устройство. Для всех трёх:

- без различий по ролям (**Admin** и **User** видят одинаково);
- текст читаем в светлой и тёмной темах (CSS-переменные из `src/app/globals.css`);
- полная навигация с клавиатуры и заметный focus-state у интерактивных элементов;
- контент центрирован по экрану, вёрстка адаптивная;
- иллюстрация в стиле продукта-консистентная (иконка/картинка из макета).

### Not Found (404)

Показывается, когда: открыт несуществующий URL, маршрут не объявлен, страница удалена или недоступна, ошибка навигации (404).

- **Иллюстрация:** для отсутствующей/сломанной навигации.
- **Текст:** `This doesn’t seem to be the page you were looking for. Let’s get you back on track.` — первая фраза может быть визуально выделена.
- **Кнопка:** `GO BACK` — возвращает на предыдущую страницу; состояния default / hover / pressed.
- **Figma:** [Not found](https://www.figma.com/design/m3zxmLv79A6MsHCuAIQAoo/CV-Builder?node-id=21482-1601&t=bVJj7VwkbTDpGdCV-0)

| --- | --- |
| AC-1 | Показывается для невалидного URL / отсутствующего маршрута / удалённой страницы |
| AC-2 | Есть иллюстрация отсутствующей страницы |
| AC-3 | Показаны текст ошибки и кнопка `GO BACK` |

### No Internet

### Device Error (неподдерживаемое устройство)

Показывается, когда ширина экрана **меньше `768px`**: открытие на неподдерживаемом мобильном устройстве или уменьшение окна до этой ширины после ресайза.

- **Иллюстрация:** неподдерживаемое мобильное использование.
- **Текст:** `This app isn’t supported on mobile devices. Please open it on a desktop or tablet to continue.` — ключевая фраза может быть визуально выделена.
- **Figma:** CV Builder – Mobile Unsupported (ссылка в макетах; отдельного URL в требованиях нет).

| AC-2 | Есть информационная иконка |
| AC-3 | Показано сообщение о неподдерживаемом устройстве |
| AC-4 | Light / Dark темы |
| AC-5 | Контент центрирован |
